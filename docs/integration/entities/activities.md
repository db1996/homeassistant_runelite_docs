# Activities

All OSRS hiscores activities (bosses, clue scrolls, minigames) have their own sensors. They update every 6 hours from the OSRS hiscores.

For the skill you are training right now, see [Current Activity](/integration/entities/current-activity).

## Entity ID

`sensor.runelite_%username_activity_%activityname`

## State

- Score (kill count)

## Attributes

- `id`: OSRS activity ID
- `name`: friendly name
- `rank`: hiscores rank
- `score`: current score
