# Services

This integration exposes multiple Home Assistant services to:

- Set timers (farming, birdhouses, compost)
- Update entity states (dailies, patches, Miscellania)
- Refresh the OSRS hiscores
- Trigger events (notifications, testing)

## Categories

- Farming & timers
- Shortcut services
- Dailies
- Kingdom of Miscellania
- Entity data (`set_entity_data`, `set_multi_entity_data`, `fetch_osrs_highscores`)
- Test event triggers
