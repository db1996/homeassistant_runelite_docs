# Entities

This page lists all entities created by the integration (sensors for skills, activities, farming patches, player status, etc.).

## Naming conventions

Most entities follow this pattern:

`runelite_%username_<type>_<name>`

## Categories

- Farming & Birdhouses (including the compost bin)
- Farming tick offset
- Skills
- Activities
- Current Activity
- Dailies
- Player Status
- Status Effects
- Aggression Timer
- Slayer Task
- Quests
- Inventory & Equipment
- Kingdom of Miscellania

The integration also creates [event entities](/integration/triggers/#event-entities) for the plugin's events.
